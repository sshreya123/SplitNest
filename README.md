# SplitNest

SplitNest is a full-stack group expense-sharing application that helps users
split expenses, track balances, manage groups, and record settlements.

## Technology Stack

### Frontend

- React
- TypeScript
- Tailwind CSS

### Backend

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL

## Planned Features

- User registration and login
- JWT authentication
- Expense groups
- Group member management
- Equal, exact and percentage expense splitting
- Balance tracking
- Payment settlements
- Expense history
- Personal dashboard
